## Docker Installation

Hello there!  
  
Just a quick note to remind you to download and install Docker on your computer for the Foundation of Data Engineering course [OT7].  
  
Here are the links for installation:  

- Windows: [Docker for Windows](https://docs.docker.com/desktop/install/windows-install/)  
    
- Linux: [Docker for Ubuntu](https://docs.docker.com/engine/install/ubuntu/)  
    
- Mac: [Docker for Mac](https://docs.docker.com/desktop/install/mac-install/)  
    
After installation, please verify by running the command:  
  
docker run busybox hello!  
  
Don't forget to clone the course repositories:  

- Today’s class on Docker: [dockertp](https://github.com/riccardotommasini/dockertp)  
    
- TP’s class: [dataengtp](https://github.com/riccardotommasini/dataengtp)  
    
You can pre-download all Docker images necessary with this command:  
  
```
	docker compose -f docker-compose.for.pull.yml pull
```
